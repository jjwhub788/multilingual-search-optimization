# RQ4: 같은 보완 정보 30건에 대한 표현·검색 방식 비교

## 조건
기존 개발 관광지 19곳의 AI 작성 검색 의도 19개 × 세 언어 57개에 대해 동일한 언어의 TourAPI 문서 138개를 검색했다. BGE-M3, 제목+설명, 최대 2,048토큰. 모든 방식은 정보 부족도 전략으로 기존에 선택된 같은 보완 정보 30건을 사용하며 18개 장소·언어 문서에 해당한다. 보완하지 않은 문서는 그대로 둔다. 각 정보의 자연어형과 항목형은 팀원이 제공한 표현이다. 비용은 정보 개수로 통제했으나 토큰 수·비용은 다를 수 있다.

자연어형과 항목형은 원문에 각 표현을 덧붙여 문서 하나로 임베딩한다. 필드형은 원문과 각각의 항목형 정보를 따로 임베딩하고, 질의와 기본 문서 또는 개별 필드 사이 코사인 유사도 중 최댓값을 문서 점수로 삼는다. 따라서 필드형은 구조뿐 아니라 점수 결합 방식도 다르며, 결과 차이를 구조 자체의 효과로 단정할 수 없다.

## 결과
|조건|R@1|R@5|MRR|
|---|---:|---:|---:|
|원본|80.70%|92.98%|0.8677|
|자연어형|82.46%|98.25%|0.8902|
|항목형|80.70%|98.25%|0.8756|
|필드 최대점수형|63.16%|82.46%|0.7364|

원본 대비 순위가 낮아진 검색어는 자연어형 0개, 항목형 0개, 필드형 17개다. 필드형에서 순위가 떨어진 17개 모두 1위는 보완 대상으로 선택된 다른 문서였다. 이는 일반적인 필드 점수가 특정 문서의 순위를 높였을 가능성과 일치하나, 직접적인 원인 확정에는 점수별 추가 분석이 필요하다. 원본과 자연어형 순위는 독립적으로 기존의 원본·부족도 실험 저장 순위와 전부 일치했다. 모든 입력은 2048토큰 이하였다.

## 주의
평가 질의와 보완 대상을 개발 과정에서 알고 있었고, 정답의 독립적 사람 검토와 복수 정답 판정이 완료되지 않았다. 장소 19곳에서 각 언어 3개의 질의가 파생되었으므로 관광지 57곳이 아니다. 부트스트랩은 탐색적이며 독립적인 최종 평가나 성능의 일반화 근거가 아니다. 근거와 입력 해시는 메타데이터에 있다.
